# Agregador-de-planilha
Lançar, esperar e usar! Para windows, agrega em um arquivo xlsx, ou csv uma aba comum em várias planilhas recursivamente buscadas em um diretório pai ou arquivos selecionado.

Você precisa ter o Python 3 Instalado.

Como compilar?
Clique em "Compilar" e espere até que o prompt de comando indique o local em que o Agregador de Planilhas foi salvo.

Link do Projeto compilado: [Agregador de Planilhas]([https://www.exemplo.com](https://drive.google.com/file/d/1CrYHX1ylJL5qWFTQaN1ZNi4tzar4tPsM/view)
